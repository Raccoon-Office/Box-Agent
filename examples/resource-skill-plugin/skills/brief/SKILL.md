# Brief

Use this Skill when the user asks for a concise brief from material already in the conversation.

1. Identify the user's intended audience and requested output language. If neither is specified, follow the user's language and write for a general reader.
2. Summarize the supplied material in a short paragraph.
3. List confirmed facts, assumptions, and open questions separately when those categories are present. Do not invent facts or imply external verification.
4. Keep the result in the conversation unless the user asks for a file.

This example requires no configuration, network request, model credential, extra tool, or plugin worker. It demonstrates loading a Skill from an external resource package.
