### 5.1 替换既有能力的升级矩阵

替换内置或已有 Skill 时逐项验收；纯新增能力可标不适用并写明理由。记录升级前版本、实际宿主构建摘要、交付包摘要、active/saved 状态以及发现和调用结果。源码检查、包自检、构建产物检查和真实宿主业务验证分别提供证据，不继承其他构建的结论。

当前 PPT 的完整迁移要求：固定插件包和依赖交付，八个贡献全部暴露，完整绑定 `pptx`、`ppt-fast`、`sn-ppt-entry`、`sn-ppt-story`、`sn-ppt-standard`、`sn-ppt-dazzle`、`sn-ppt-tools`、`sn-ppt-doctor`，并经真实宿主启动确认。部分或无别名属于并存部署，不能填写“完整迁移通过”。
