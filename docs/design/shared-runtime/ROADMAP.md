# 桌面共享核心优化任务总览

长期目标、四阶段验收和云端／多语言扩展条件见 [长期演进方案](LONG_TERM_PLAN.md)。本文负责模块分解与工作包顺序。

本表将 [harness 评估](../harness-review-cn.md) 的 18 个细分评审领域按职责合并为 14 个模块，用于跟踪开发范围。模块不是单个提交；T1–T12 是已经拆出的可独立评审工作包。完成某个工作包不代表该模块全部建议已实现。

**当前最高优先级：System Prompt 与 Tool 使用质量。** System 是跨模块专项，在下表关联位置落实，不能仅归为 Context 压缩；Tool 优化包含能力定义、发现、参数、结果和执行。先做最小基线和效果优化，纯架构整理后置。具体固定边界、功能变化与评估标准统一见长期方案第 4 节。

| --- | --- | --- | --- |

## 按优先级推进的工作包

**P0-Q0** 的清单、最小任务集和确定性入口已由 [T13](T13-minimal-quality-baseline.md) 落实；[T13a](T13a-profile-trace-capture.md) 补齐首轮真实基线，七例 5 通过、2 失败，并保留评估入口故障及单例复测。后续 System／Tool 优化据失败归因另拆方案，真实对照需固定配置并重复运行。

[T14](T14-runtime-instruction-provenance.md) 落实 P0-S1 的共享注入管理模块，统一类型、来源、配套提示词以及排队、去重、取消和回执。来源修正阶段的两轮真实请求对照与管理模块回归分开记录。小预算下的提前收尾归 P0-S2，下一项 T14a 单独定义策略与验收；沙箱初始化超时先独立复核执行环境。T14 不代表全部 System 分层与装配工作完成。

| 顺序 | 工作包 | 产出 |
| --- | --- | --- |
| 1 | P0-Q0 最小基线 | T13/T13a 已有清单、任务、验收器和首轮真实记录；费用未知，重复模型对照留给各优化工作包 |
| 2 | P0-S1 System 分层与装配 | 来源、优先级、作用域与版本；消除冲突和重复，按实际能力注入 |
| 2 | P0-T1 工具定义与参数 | 能力粒度、描述、schema、示例和错误指引；与 S1 分开改动和评估 |
| 3，按失败归因选取 | P0-S2 System 行为策略 | 计划、工具使用、失败恢复、等待用户、续跑和完成判断 |
| 3，按失败归因选取 | P0-T2 工具发现与暴露 | 常驻工具集、按需搜索、激活与能力缺失反馈 |
| 3，按失败归因选取 | P0-T3 工具结果与反馈 | 可用摘要、结构化状态、恢复指引、裁剪与完整证据 |

每项先固定通过标准和基线，再改变一个主要因素；确定性契约测试与真实模型效果评估分别记录。基线服务于立即开展优化，不以建设完整评估平台为前提。纯架构收敛、云端化及语言迁移不得占据这条主线的优先位置；阻断性的权限、数据完整性和运行故障及时修复。

## 已有工作包与后续架构队列

以下保留原工作包编号用于追溯，不再代表下一项应先做 Kernel 重构；其中任务评估由 P0-Q0 及后续 System／Tool 工作包优先落实。

1. **P0-1 基线与结果分类**：T2 完成运行终止分类；任务级质量/成本评估基线仍待建立，不能将 COMPLETED 视为目标验收通过。
2. **P0-2 父子共享预算**：T5 完成当前进程内工具调用硬额度；跨进程预算服务不在本轮范围。
3. **P0-3 事件容量与消费生命周期**：T1/T3/T4 完成，T6/T10 覆盖宿主链路。
4. **P0-4 去重、副作用与重试契约**：[T12](T12-explicit-tool-deduplication.md) 已实现可信显式批内去重；资源冲突、effect 分类和重试策略仍待独立方案，不一次引入 DAG 或自动重试。
5. **P1-1 主循环职责收敛**：为 System／Tool 质量工作提供必要边界；独立整理在质量主线之后，固定轨迹后逐项提取。
6. **P1-2 请求预算账单与压缩保真**：先建立测量和验证，再调整算法。
7. **P1-3 提交矩阵与恢复故障注入**：明确 durable 与 outcome unknown，验证中断恢复。
8. **P1-4 跨宿主续跑和权限一致性**：共享通用编排，保留宿主渲染与 Provider timeout 权威。
9. **P2 按测量结果优化**：MCP 职责拆分、Memory 检索、日志派生快照等。

T7–T9e 是验证过程中拆出的兼容与真实缺陷修复，不替代上述未做的架构工作。后续每个实现任务继续先写方案，区分固定边界与功能变化，包含回归证据并独立提交。

长期方向保留桌面独立 Agent 能力和共享核心；暂不建设网页/云服务、多语言执行协议或替换核心语言。开发版联调与正式 runtime 的构建、安装、重启、真实任务验收分开记录。
