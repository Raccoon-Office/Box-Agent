# T9c 运行日志创建防覆盖

## 修改方案

- 固定边界：日志目录、内容、查询入口、权限策略、运行及 ACP 行为不变。
- 保持行为：保留 `agent_run_` 前缀和 `.log` 后缀，按现有入口发现日志。
- 功能变化：使用独占创建；时间戳冲突时选择带递增后缀的新文件，不能覆盖其他运行日志。跨 logger 实例同样适用。
- 兼容影响：消费者不能假定文件名只包含时间戳；仓库当前读取入口使用实际文件路径，不按固定长度解析文件名。
- 验收：冻结时钟，同一实例和不同实例先后创建日志，所有路径独立、旧内容完整保留；相关日志与 CLI 回归。
- 回退：单独回退此提交；已生成日志无需迁移。

## 实施与验证

实现使用 `Path.open("x")` 独占创建；名称冲突时增加后缀，仅捕获 FileExistsError，其他文件错误照常暴露。日志内容和记录顺序保持原样。

原失败用例改为冻结同一时间戳，并覆盖同一个 logger 与不同 logger 实例；先写入第一份日志的内容，再验证后续创建没有覆盖它。
