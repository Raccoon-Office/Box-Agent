# T2：运行终止分类

## 修改方案

- 固定边界：原 status、stop_reason、停止/续跑策略及 ACP 消息不变。
- 功能变化：RunResult 增加只读派生字段 termination_kind，JSON 输出新增同名字段；旧构造方式不变。
- 分类：end_turn→normal；max_steps/max_tokens→budget_exhausted；interrupted/cancelled/waiting_for_user/error 分别映射 interrupted/cancelled/waiting_for_user/failed。第三方未知原因映射 unknown，不推断成功。
- 正常结束不代表目标已验证完成。消费者依据新字段区分结束性质。
- 验收：全部 StopReason、未知原因、旧构造、序列化及原映射。
- 回退：回退提交；下游需容忍字段缺失，不要求宿主立即迁移。

## 实施与验证

实际与方案一致，字段使用 init=False，禁止调用方提供矛盾分类。

验证：`.venv/Scripts/python.exe -m pytest tests/test_run_api.py tests/test_sdk.py tests/test_run_delivery.py -q`：35 passed。源码测试完成，未构建安装。
