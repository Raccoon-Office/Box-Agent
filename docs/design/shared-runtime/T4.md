# T4：容量与背压

## 修改方案

- 固定边界：未触及限制时正文、分片、顺序和 ACP 映射不变；不合并、不静默丢弃、不写磁盘。
- 功能变化：默认 1,024 条、4 MiB UTF-8 JSON envelope 负载，双低水位 50%，连续拥塞 30 秒失败。单事件超过字节上限立即失败。
- 公共接口：RunDeliveryOptions 经 AgentService.start、AgentClient.start/run 传入，不增加配置文件或 ACP 字段。参数必须为正、超时有限。
- 序列化计量每个事件一次；publish 锁覆盖待入队操作，序号按入队顺序。上限不代表整个进程内存，结果聚合、生产中事件及序列化临时内存不在队列额度内。
- 控制：通道取消/关闭独立唤醒，结果 Future 独立完成。交付错误优先成为失败结果，不被已产生的 Done 或工具层错误包装掩盖。
- 验收：数量/字节/单条限制、双低水位、受控超时、并发发布、满队列取消、仅结果模式以及公开入口回归。
- 回退：回退本提交；消费模式保留 T3。大结果调用方需显式提高运行交付额度或使用既有工具结果引用。
