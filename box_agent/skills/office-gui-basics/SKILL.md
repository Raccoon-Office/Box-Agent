# Office 界面基础操作

通过 CUA 工具操作 Office 应用。工具参数、AX 编号、截图坐标和恢复方式见 [mac-cua](../mac-cua/SKILL.md)。本技能提供文件对话框和 Word 文本编辑的操作方法，按当前界面和任务选择使用。

## 打开文件

可从应用的“文件”菜单或 `cmd+o` 打开文件对话框。观察弹窗后，可以浏览文件列表，也可以输入已知路径。

通过路径打开文件的一种流程：

1. 在打开对话框中按 `cmd+shift+g`，观察“前往文件夹”的路径字段。
2. 根据字段和操作选择输入方式：`set_value` 替换可写字段的完整值；`type_text` 在光标或选区处输入；`paste` 向输入目标粘贴。使用后两种方式替换旧路径时，先确认焦点和选区，按需用 `cmd+a` 全选。
3. 核对字段中的目标路径，按 Return，并观察导航结果。
4. 如果返回打开对话框且目标文件已选中，使用“打开”按钮或 Return 打开文件。
5. 根据文档标题及内容确认打开的是目标文件。列表中的选中行或预览不代表文档已经打开。

路径字段可能声明 `confirm`，可按控件行为选择该动作或 Return，并以随后实际导航结果判断是否提交成功。

## 从文件列表选择

列视图中的文件名可能暴露为 `AXList` 下的 `AXTextField`。若点击文件名没有选中或打开文件，可以切换为列表视图：

1. 从视图菜单选择“列表”，重新观察文件行。
2. 选择目标文件所属的 `AXRow`，检查选中状态和“打开”按钮。
3. 使用“打开”按钮打开文件。

这是文件名子控件操作无效时的一种替代方法。也可以根据实际界面使用双击、截图坐标或路径输入。AX 中显示某个动作，只说明控件声明了该动作；是否选中或打开仍看执行后的界面。

## 保存与另存为

按用户要求确定是保存原文件，还是另存为副本。需要保留原件时，将修改保存到另存目标。

从应用菜单或界面按钮进入保存／另存为对话框后，核对目标目录、文件名和文件格式。可以通过目录控件选择位置，也可以按 `cmd+shift+g` 输入目标目录，再填写文件名。

使用路径定位时：填写目录路径，按 Return，确认对话框已进入目标目录，然后填写文件名并操作“保存”。目录路径和文件名字段分别处理。不同父目录下可能有同名文件夹，确认位置时结合完整路径或父目录判断。

字段使用 `set_value`、`type_text` 或 `paste` 的选择与打开文件时相同。字段值变化与文件保存完成是两件事；根据保存对话框、文档标题及后续界面确认保存结果。

## Word：选择和替换文本

编辑已有文档时，先读取要修改的内容及其相邻段落。AX 没有正文时使用截图，根据任务确定替换范围。

- 只替换标题或段落中的文字时，留意选区是否包含末尾段落标记。包含段落标记的替换可能把下一段合并进来。
- `Shift+End` 或整行选择的范围取决于光标位置与文档布局；替换前观察选区，替换后核对相邻段落是否仍分开。
- 在正文光标或选区处使用 `type_text` 或 `paste` 编辑。`set_value` 替换可写字段的完整值，不能把它等同于正文中的局部替换。
- 局部编辑后检查指定文字、下一段开头、段落顺序及格式，保留任务未要求修改的内容。

## Word：追加内容

先确认光标位置，再插入文本。Word for Mac 中，`cmd+down`／`cmd+up` 用于段落导航；文档末尾／开头使用 `cmd+end`／`cmd+home`，随后观察实际位置。

需要新增段落时使用段落换行；软换行仍属于同一段。追加后核对内容所在位置、是否只出现一次，以及原有末段是否完整。

## 核对与修正

利用操作过程中返回的截图核对文字、段落边界、顺序、数值、选中状态和布局。文件名变化、字数正常或保存弹窗关闭，分别只能说明相应状态，不能替代正文检查。

发现段落合并、漏字、重复输入或位置错误时，根据当前状态撤销相应编辑或修正明确的范围，再核对结果。是否需要额外截图或重新打开文件，由尚未确认的内容和用户要求决定。
