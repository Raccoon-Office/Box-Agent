# Office 界面基础操作

使用 [computer-use](../computer-use/SKILL.md) 绑定目标 Office 应用，在 `cua_repl_js` 中复用 `app`。

## 打开文件

用“文件”菜单或 `cmd+o` 打开对话框，根据当前界面选择路径或文件行。

- **macOS 系统选择器**，已知路径时按 `cmd+shift+g`，确认出现路径输入框，从最新 AX 取可写字段编号，用 `await app.setValue(id, path)` 填入完整路径。若需键入或粘贴，先确认字段有焦点，替换旧值时先全选。读回路径，按 Return，用 `await app.getAXState()` 核对导航结果。
- **WPS 自定义选择器**，若快捷键后仍是原面板，按面板现有的目录和文件行导航。只有确认“文件名称”是可写字段，或点击后看到了文字光标，才在其中填路径；读回完整值再点“打开”。AX 标为弹出按钮时先展开看选项。打开后核对文档标题。
- **从列表选择**，列视图中的文件名可能是 `AXTextField`。点文件名未选中时，切到列表视图，从最新 AX 选择目标文件所属的 `AXRow`。

若仍在打开对话框，确认选中了目标文件再点“打开”。进入文档后用标题和内容核对文件。

## 保存与另存为

要求原路径时，保存当前文档。要求副本时，选择“另存为”，在对话框通过目录控件或 `cmd+shift+g` 定位目标父目录，确认位置后填写文件名、核对格式，再点“保存”。原路径保存后，核对当前文档及保存状态。另存后若界面只能看到同名文件的标题、无法确认父目录，就从用户指定的完整路径重新打开，并核对一处本次修改，再报告交付位置。

## Word 文本编辑

先从 AX 读取目标文字和相邻段落，正文不可见时用截图定位。

- **替换**，核对选区的两端。`Shift+End` 的选区取决于光标和布局，只替换文字时保留末尾段落标记，以免合并下一段。
- **追加**，Word for Mac 用 `cmd+end`／`cmd+home` 到文末／文首，`cmd+down`／`cmd+up` 用于段落导航。读回光标位置，新增段落时使用段落换行。

确认光标或选区后，用 `await app.typeText(text)` 或 `await app.paste(text)` 编辑。核对文字只在目标位置出现所需次数、相邻段落边界及格式保持正确。有漏字、重复或段落合并时，只撤销或修正已确认的编辑，再读回结果。

替换文字后还要设置标题样式时，先读回新文字。若粘贴提示遮住目标，只在能辨认关闭控件时关闭它，或从可见位置重新定位目标段落。用最新 AX 或截图确认插入点位于该段，再应用内置样式；核对样式名称与段落文字后保存。

## Excel：提交选区后再设置格式

名称框显示地址后，仍需在工作表上核对选区。

从最新 AX 取名称框编号，用 `await app.click(id)` 进入编辑，读回 AX 确认焦点。用 `await app.pressKey("super+a")` 选中旧地址，按任务范围粘贴，例如 `await app.paste("A2:F9")`。焦点或粘贴结果有疑问时，先单独读完整 AX，确认名称框中的地址与目标范围一致；仍无法确认就停在这一步。确认后用 `await app.pressKey("Return")` 提交。看到行列高亮、单元格边框或选中状态与目标范围一致后，再执行格式操作。

提交后若工作表仍未选中目标范围，先观察焦点。工作表已获得焦点时，可用 `await app.pressKey("ctrl+g")` 打开“定位”。从最新 AX 找到可写的引用位置字段，用 `await app.setValue(id, range)` 填入本次范围，读回地址再点当前“确定”。回到工作表后核对选区的行列边界。整表排序应选中所有关联列，并按实际选区设置是否包含表头。

填一列公式时，先确认键盘焦点已回到工作表。先在首个目标单元格输入公式，观察编辑位置，再单独提交；选回该格，在公式栏核对公式后再填充其余行。若只拍到“名称框”的小浮层，先读完整 AX 和窗口列表；只有重新确认工作簿、目标单元格和焦点后才继续输入。

排序前读回排序列、顺序和表头设置，提交后核对首尾记录以及同一行的关联字段。格式任务则核对显示效果和底层数值。核对后按上面的保存流程写入指定路径。

## PowerPoint 占位框

1. 从当前截图核对页码和版式，辨认标题、副标题或正文占位框。用新图上的坐标点进目标框，再取图确认。
2. 看到目标框内的文字光标或文字选区，下一格才用 `await app.paste(text)` 粘贴完整内容。仅见外框控制点时，先进入文字编辑并取图。用 `super+a` 替换文字前，先确认光标在要替换的框内。
3. 粘贴后取图核对当前页、原占位框和完整新文字。三项都正确就继续下一项；局部裁图的像素统计不能作为撤销依据。切页时确认左侧选中的缩略图和状态栏的页码，再编辑下一页。完成后保存，按任务要求切回相应页面核对。
