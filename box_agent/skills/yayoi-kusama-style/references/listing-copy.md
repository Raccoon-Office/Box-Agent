# 上架文案

## 短名
草间弥生风格

## 一句话
用自我消融和无限重复，而不是圆点贴纸，做草间向的画面、空间和致敬方案。

## 列表简介（约 80–120 字）
波点不是装饰。先锁草间的年代，再锁一套母题（网 / 波点场 / 南瓜 / 镜屋亚型 / 永恒灵魂），用自我消融和无限重复覆盖你的主题。未指定年代时默认黄黑波点场吞噬，不自动加南瓜或星空镜屋。输出 AIGC 提示词、三幕空间或产品致敬降级方案。不用于伪造原作、假联名，也不把红发自拍舱当成全部草间。

## 适用
设计师、AIGC 出图、展陈、品牌概念提案。

## 不适用
假授权、名作复刻商品、装饰性三颗圆点、病理猎奇。

## 推荐提问
「用草间风格画被波点吞没的地铁车厢，要自我消融。」
