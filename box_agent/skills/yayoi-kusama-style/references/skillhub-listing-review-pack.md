# SkillHub 正式上架版说明

## 1. 上架名称

- 英文名称：`yayoi-kusama-style`
- 中文名称：`草间弥生风格`
- 当前版本：`1.2.0`

## 2. 一句话介绍

先锁草间的年代与母题亚型，再把自我消融做成可执行的画面、空间和产品致敬方案。

## 3. 适用用户

- 需要草间向 AIGC 提示词的设计师与内容团队
- 做快闪/展陈概念的策划
- 需要「像草间但不要假联名」的品牌提案

## 4. 解决的问题

| 常见问题 | 本技能提供的能力 |
|---|---|
| 只会写 in the style of Kusama | 命题→母题→密度→正反提示词 |
| 圆点墙纸冒充风格 | 铺满/吞噬验收 + 反例 |
| 沉浸展做成打卡棚 | 审视→纵情→消融三幕 |
| 假联名风险 | 产品 playbook 风险表与拒答 |
| 空壳风格包 | 专访蒸馏进 philosophy / source-map |

## 5. TRACE 自检映射

| 维度 | 本包证据 |
|---|---|
| Trust | AGENTS 红线、不伪授权、源文不全文转载 |
| Reliability | 四模式路由、质量清单、validate 脚本 |
| Adaptability | 画/空间/产品/标题；缺主题有默认 |
| Conversion | 输出模板可粘贴；降级话术可直接用 |
| Effectiveness | 正反例、before-after、测试 Prompt |
