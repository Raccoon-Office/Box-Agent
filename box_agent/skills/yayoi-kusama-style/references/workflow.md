# 生产流程

## 0. 入口

1. 判定模式 A/B/C/D。  
2. 扫描红线：假授权、精确复刻、猎奇病理、装饰三点、无标记混搭。  
3. 命中 → [boundary-rules.md](boundary-rules.md)。  
4. 否则进入 1。

## 1. 锁年代

填：

```text
期：1起源 / 2网 / 3积累身体 / 4文字期 / 5南瓜公共化 / 6永恒灵魂 / 7终章
用户是否点名镜屋/南瓜/网/灵魂：
```

未指定：期不写死为 5；**默认波点场吞噬**，明确不加南瓜、不加 LED 星空舱。  
点名镜屋：打开 [style-patterns.md](style-patterns.md) 亚型表，锁一行。  
点名「经典草间/最像网红展」：可走期 5，但仍须消融验收，并警告不要直岛复制品。

## 2. 命题一行

```text
命题：
主体：
必须保留的识别：
不可出现：
```

默认：命题=自我消融；不可出现=红发人设、稀疏圆点、时代混片。

## 3. 母题唯一化

一套主母题。例外：

- 南瓜进对应亚型的镜屋 → 主次写清（期 5）。  
- 网 + 永恒灵魂眼睛 → 两版方案，不混一帧。

## 4. 配色 + 密度 + 材质

各锁一项，配色跟年代走。产品再标功能留白。

## 5. 分模式生产

- A：`playbooks/aigc-image.md`（提示词写上分期，negative 写人设与混片）  
- B：`playbooks/spatial-immersive.md`（第三幕写亚型）  
- C：`playbooks/product-homage.md`  
- D：`phrasebook/prompt-language.md`

## 6. 自检四问

1. 拿掉姓名，是否仍在做无限或消融？  
2. 会不会被看成时尚波点布 / LV 印刷点？  
3. 会不会被看成假冒原作？  
4. 是否把 1965 和 2013 镜屋画成同一间？

任一失败 → 重写。

## 7. 交付

套 `templates/output-template.md`。第一行必须有**期或年份感**。
