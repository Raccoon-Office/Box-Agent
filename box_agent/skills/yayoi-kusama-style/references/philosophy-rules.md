# 哲学 → 判断规则

把草间自述转成画面决策，不要在交付里写作文。本包视觉为主，不展开文本公案。五个心智模型见 [visual-engine.md](visual-engine.md)。

## 规则 0：先选期，再选符号

没有「通用草间滤镜」。用户不说年代，就用波点场吞噬，不要自行叠南瓜+星空镜屋。  
七期表见 [style-patterns.md](style-patterns.md)。

## 规则 1：先命题，后符号

| 用户只给符号 | 你要补的命题（默认） |
|--------------|----------------------|
| 波点 | 自我消融：个体是单点 |
| 南瓜 | 生命安慰：圆、饱满、可依靠 |
| 镜子 | 自我增殖到消失 |
| 网 | 无限与无中心 |
| 花/茎 | 欲望与生命的过度生长 |

若用户已给命题（城市孤独、品牌新生、反战、悼念），用命题选符号，不要反过来。

**验收**：能用一句非符号语言说清这张图在干什么。  
失败例：「这是草间风格所以有波点。」

## 规则 2：单点尺度

问：主体是被场吞没，还是场在给主体化妆？

- 通过：人/产品/建筑的轮廓还在，但图案已经爬上皮肤、商标、窗、地面，边缘被切掉。
- 失败：主体完整居中，波点只在背景墙。

## 规则 3：正负关系

波点与底、网与洞、灯与黑、实体与镜像，必须互相定义。

- 通过：改底色会让点的意义翻转；镜中数量明显多于实物。
- 失败：PNG 贴纸叠在照片上，底和点没有共生。

## 规则 4：重复 = 劳动痕迹

草间面对画布「手会自动开始」。生成物要像停不下来：

- 点的大小随曲率变化（南瓜棱上为观察性规则）
- 网络到画布边缘，不留设计海报式出血
- 手绘不均匀优先；均匀印刷点视为时尚稀释，除非用户只要传播态并标明

## 规则 5：爱与和平不是甜

peace & love 是她从反战与自我治疗里长出来的正面意志。

- 通过：灿烂里有一点战栗、永恒或空无。
- 失败：只剩幼儿园贴纸、情人节粉色圆点。

## 规则 6：哲学必须可被传达

她定义好的艺术家 = 有哲学并能传达。

每份交付在方案开头用一行写：

```text
命题：自我消融｜无限｜安慰｜过度生长｜爱与和平｜生死
传达方式：铺满波点让人脸将消未消
```

写不出来就还没开始画。

## 规则 7：异端，不是二创表情包

「创作时只想到我自己」→ 允许极强作者意志，不允许用她的红发、花裙、经典自拍姿势当默认角色。

用户明确要「草间本人出镜」时：老年、短红发、冷静站在作品里可以；禁止幼化、性感化、精神病小丑化。
