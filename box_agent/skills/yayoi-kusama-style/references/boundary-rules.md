# 红线与边界

## 身份

- 模仿的是**视觉与哲学范式**，不是草间本人、不是草间弥生美术馆、不是官方工作室。
- 不输出「草间亲笔」「studio certified」「可上拍」等表述。

## 原作与商标

| 行为 | 是否允许 |
|------|----------|
| 用波点场/网/南瓜**语法**做新主题 | 允许，须标明致敬 |
| 黄黑南瓜作为教学/内部概念图 | 允许，注明非原作 |
| 1:1 复刻直岛南瓜、某间镜屋用于商品或展陈落地施工 | 拒绝；改「语法致敬 + 原形改写」 |
| 假冒联名、伪授权 LOGO、伪造签名 | 拒绝 |
| 用她的姓名作为商品品牌名 | 拒绝；可用「波点无限风格」等描述 |

外部依据（调研，不在用户稿展开）：工作室/基金会曾公开打击假冒联名展，并警告伪作与假证书增多、不提供鉴定。因此「我只是粉丝效果图」不能当抗辩。

用户坚持「看起来要一模一样才能过会」时：

1. 说明风险。  
2. 给「神似语法、形不复刻」方案。  
3. 仍要求假授权则停止该部分。

## 病理与隐私

允许：一句说明波点与幻觉、自我治疗的关系（艺术史事实）。  
禁止：模拟发病过程取乐、把疗养院当恐怖片、用病名当滤镜标签。

## 死亡与追思

允许：热情、爱、永恒、继续创造。  
禁止：炒作身价、猎奇死因、用讣闻标题腔带货。

## 时代混片

用 2010s 暗室 LED 星空舱去生成 1965 茎状镜屋，或用永恒灵魂细胞眼去画直岛南瓜 → 失败。先选亚型/期。

## 传播稀释态

LV 式均匀圆点、橱窗机器人草间、老花+点，是识别度传播，不是作品语法。生成时站作品场，不站橱窗。

## 装饰波点

「在海报角落加波点增加艺术感」→ 不视为本技能成功。必须升级为铺满或拒绝宣称草间风格。

## 融合

与村上隆、奈良美智、波普、赛博朋克融合时，标题写「融合」，比例写清（如草间语法 70% / 其他 30%）。未标明的混搭视为失败。

## 人像

- 默认不画草间本人。  
- 用户要本人：老年艺术家、短红发、严肃或平静，站在作品逻辑里（人设，须标明）。  
- 《Walking Piece》粉花和服仅在用户要 1960s 作品语法时使用。  
- 禁止幼态、性化、表情包化、默认红发抱南瓜。  
- 未授权真人（明星、同事）深度伪造不属于本技能；只做风格覆盖时也须用户确认有权使用该肖像。
