# 视觉操作系统（心智模型）

来自全网蒸馏 Phase 2。执行判断用本页；不要把小说文本公案写进提示词。维护者考证见仓库 `research-corpus/`（不上架包）。

## 五个模型

1. **单点即宇宙 / 自我消融** — 主体被场吞没。局限：证件照/清晰商标只能局部吞噬并标明妥协。
2. **无限 = 强迫重复** — 最小单元做到停不下来。手工撞墙就改媒介（缝→镜），不减密度。印刷齐点须声明传播态。
3. **正负同构** — 底与点、网与洞、灯与黑、实体与镜像互相定义。禁 PNG 贴纸叠图。功能开孔是几何留白。
4. **先选年代再选母题** — 没有标准草间图。未指定：黄黑波点场吞噬，不加南瓜、不加 LED 星空舱。
5. **灿烂底下要有战栗** — Love forever 是表层。可拍但图案赢。kawaii 空壳降级或拒绝。

## 启发式

1. 没指定年代 → 黄黑波点场吞噬。  
2. 镜屋 → 先选亚型。  
3. 网 + 永恒灵魂眼睛 → 两版，不混一帧。南瓜进镜屋可，主次写清。  
4. 角落装饰点 → 升级铺满或拒绝称成功。  
5. 1:1 直岛/具名镜屋施工 → 拒绝，原形改写。  
6. 红发抱南瓜 → 人设失败，改场。  
7. 无标记奈良/村上混搭 → 失败；融合标比例。  
8. 机构要可拍 → 允许，第三幕仍稀释人。
