# Playbook：产品 / 联名致敬

## 场景名称
把草间语法用到包装、潮玩、美陈、服饰，同时挡住假联名。

## 适用信号
- 联名、周边、保护套、包装、店妆、胶囊系列

## 不适用
- 纯艺术概念图 → aigc-image
- 要官方授权文件、伪造合同 → 拒绝

## 前置检查
1. 是否已有官方授权？无 → 全程「致敬/灵感，非官方」。
2. 功能面：屏幕、按键、食安接触面、灯具出光面。
3. 销售文案是否出现「草间弥生」姓名商标：默认用「无限波点风格」描述，姓名只出现在内部创意说明，除非法务允许 nominative 艺术评论用法。

## 执行步骤
1. 选语法不选名作：要「棱上变径圆点的饱满体」，不要「直岛那颗南瓜」。  
2. 原形改写：换物种（耳机、瓶子、建筑体块）、换比例、换一种配色对。  
3. 密度：可见表面 ≥ 80% 被点/网覆盖，功能留白单独标注。  
4. 文案：禁止「Kusama 联名」「草间授权」。可用「向无限重复致敬」。  
5. 给一张风险表：高（姓名+南瓜黄黑+镜屋复制）/ 中（黄黑南瓜体）/ 低（自有产品被波点场吞噬，无南瓜无姓名）。本表不是律师意见，不得写「商用无风险」。  
6. 禁止 LV 老花+均匀圆点当「官方联名效果图」。均匀印刷点若出现，标明「传播稀释态，非作品语法」。

## 判断标准
- 成功：产品仍能用 + 场在吞没产品 + 文案不假冒。
- 需降级：营销强要姓名 → 改为内部提案水印「概念，非对外稿」。
- 应拒答：假冒授权、卖「草间同款镜屋套件」。

## 失败与恢复

| 失败类型 | 处理 |
|---|---|
| 缺输入（没产品图） | 用文字产品类型继续，标假设 |
| 法务过不了姓名 | 去姓名、去南瓜、保留铺满波点场 |
| 用户要 1:1 南瓜潮玩 | 拒绝复刻；给「饱满有棱体+变径点」新造型 |
