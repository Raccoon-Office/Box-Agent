# Playbook：空间 / 装置 / 展陈

## 场景名称
用 2019 上海复星个展提炼的三幕，给沉浸空间写概念，而不是做打卡棚。

## 适用信号
- 展览、快闪、橱窗、沉浸式、镜屋、走廊、美陈动线

## 不适用
- 单张图提示词为主 → aigc-image（可把三幕各出一张概念图）
- 卖复制南瓜雕塑 → product-homage + 红线

## 前置检查
1. 场地：一层/多间/仅橱窗。未知则按「三间连续」写概念。
2. 是否允许观众拍照：默认允许，但拍照不得成为唯一目的。
3. 安全：镜面、充气、狭窄走廊要提一句疏散与碰撞。

## 执行步骤

按人生逻辑写三幕，可删减但不可颠倒成「先消融再审视」除非用户要反讽版并标明。

### 第一幕：审视
- 窄、长、镜。
- 平面镜 + 凸面镜（凸面镜当「巨大波点」）。
- 目标：观众不断看见自己，略感战栗。
- 禁止：宽敞网红走廊、美颜灯。

### 第二幕：纵情
- 高空间、单一配色对（默认黄/黑或用户品牌色转译成一对）。
- 茎状/充气/软体缠绕，人可走入图案。
- 目标：荒诞、童趣、仍逃不出场。
- 禁止：游乐场无命题的球池。

### 第三幕：消融
- 先锁镜屋亚型或改走消融之屋（全白被点占领）。默认若用户说「宇宙/星空」才用 2000s LED；若说「最早的镜屋」用茎铺地。
- 目标：自我消融，不是「人好小好可爱」。
- 禁止：无内容的镜面自拍间；用 Broad 星空舱冒充 1965。

入口可用南瓜等符号，但南瓜是门，不是全程主角。黄点南瓜作入口属展览结构，不要让它占领三幕。

第三幕亚型速查（必须写进交付）：

| 用户命题 | 第三幕 |
|----------|--------|
| 消失 / 宇宙 / 星空 | 2000s 暗室 LED（实物少、灯点多） |
| 最早的镜屋 / 1960s | 茎铺地：白底红点织物茎 + 镜 |
| 南瓜 | 南瓜箱：镜中南瓜无限，不是海边直岛复制品 |
| 覆盖 / 观众参与 | 消融之屋：仍见部分白底 |
| 未说 | 先问或给 LED 与茎铺地两版 |

机构限时 1 分钟是运营规则，不是美学。可拍，但第三幕目的仍是稀释人。

## 判断标准
- 成功：三幕各有一种身体感觉（被看 / 被裹 / 被稀释）。
- 需降级：只有一间房 → 压缩为「白室被点吞噬」的消融之屋过程。
- 应拒答：按某间现成镜屋抄施工尺寸用于商业复制。

## 失败与恢复

| 失败类型 | 处理 |
|---|---|
| 客户只要打卡 | 保留可拍，但把第三幕做成必须停留的暗室 |
| 场地只有橱窗 | 一层：外审视（反射玻璃）内纵情（密集点） |
| 品牌色太多 | 压成一对正负色 |
