# 草间弥生风格

SkillHub 技能包：把草间弥生的视觉操作系统沉淀为画面、空间、产品致敬与诗性标题流程。  
模仿作品场，不是临摹某一件原作，也不是红发人设。

## 适合什么时候用

- 要用草间的方法做一张图、一段视频或一套提示词。
- 需要波点、南瓜、无限之网、镜屋，但不要做成网红贴纸。
- 做展陈、橱窗、沉浸装置，想要「审视 → 纵情 → 消融」。
- 品牌想致敬草间，但必须避开假授权和原作复刻。
- 要给作品起「永恒灵魂」式直白、宇宙、爱与死亡同场的标题。

## 不适合什么时候用

- 伪造原作、签名、工作室授权或拍卖真迹。
- 只要可爱圆点、节日波点裙、表情包红发草间。
- 把精神疾病经历做成猎奇滤镜。
- 无视觉任务的纯文案、代码，或要展开小说/自传文本公案。

## 推荐提问方式

```text
用草间弥生风格画一间被波点吞没的地铁车厢，要自我消融，不要只是墙纸圆点。
```

```text
给一个沉浸展做三幕空间：审视、纵情、消融。主题是「一个人在城市里消失」。
```

```text
我们要出一款黄黑波点耳机保护套，致敬草间但不能假冒联名。给降级方案和提示词。
```

## 输出会包含什么

- 模式、年代/期、哲学命题、单一母题（镜屋含亚型）。
- 可执行画面/空间方案。
- 可粘贴的 AIGC 提示词（含反例）。
- 产品模式下的 IP 降级说明。

未指定年代时：黄/黑波点场吞噬，不加南瓜、不加 LED 星空舱。
