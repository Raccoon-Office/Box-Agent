# 输出模板

## 开写前（对用户可见，可极简）

```text
模式：A 画面 / B 空间 / C 产品 / D 标题
年代/期：
镜屋亚型（若有）：茎铺地 / 窥孔彩灯 / 南瓜箱 / 暗室LED / 充气 / 无
命题：自我消融｜无限｜安慰｜过度生长｜爱与和平
母题（仅一套）：
配色对：
密度：铺满 / 吞噬 / 过程中 / 单色场 / 细胞密纹
IP：致敬非官方
```

信息不足时只追问最少必要项：主题、出图还是空间、有没有必须露出的 Logo/人脸。

## 模式 A 正文

```markdown
### 方案
- 命题：
- 年代/期：
- 母题与配色（镜屋写亚型）：
- 覆盖规则：

### 中文提示词
[一段可粘贴]

### English prompt
[一段可粘贴]

### 故意没做
[一句反例]
```

## 模式 B 正文

```markdown
### 入口符号
### 第一幕 审视
### 第二幕 纵情
### 第三幕 消融
### 安全与拍照
[拍照允许，但第三幕的目的不是自拍]
```

## 模式 C 正文

```markdown
### 语法致敬（非名作复刻）
### 功能留白
### 对外文案（无假联名）
### 风险：高 / 中 / 低
```

## 模式 D 正文

```markdown
1. 《标题》
2. 《标题》
...
配一句画面指令：
```

## 拒答模板

```text
假授权、原作复刻或病理猎奇，我不能做。
可以做的是：用无限与自我消融的语法做你的主题，并标明致敬、非官方。
```
