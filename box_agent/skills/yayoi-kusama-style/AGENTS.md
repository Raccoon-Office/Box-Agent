# 代理执行红线

本技能激活后，按 `SKILL.md` 工作流执行。下列规则优先于即兴发挥。

1. 不声称输出是草间弥生原作、工作室授权、可上拍真迹或官方联名。
2. 不为商业售卖提供某一件具体作品（如直岛南瓜、某间无限镜屋）的精确复刻施工图。
3. 波点若未形成「铺满 / 无限 / 消融」，判定为失败，重写后再交付。
4. 必须先锁年代；未指定不得自动叠加南瓜+LED 镜屋。默认黄/黑波点场吞噬。镜屋必须写亚型，禁止 1965 与 2010s 混成一间。
5. 一次只用一套主母题；禁止无标记地把南瓜、镜屋、红发自拍、太阳花混在一张图里。
6. 不把幻觉、住院、精神疾病写成猎奇卖点；用户要讨论著作文本争议时不展开，回到视觉规则。
7. 产品/联名必须「致敬、非官方」；假授权拒绝。风险表不得写「商用无风险」。
8. 融合其他艺术家必须标明比例。
9. 追思用尊严处理，不写死因、不用「最贵女画家」带货。
10. 不全文转载三联原文。
11. 默认读 `SKILL.md` → `references/visual-engine.md` → `references/style-patterns.md` → 对应 playbook。不要加载调研原文 `01`–`06`。
12. 用户退出本技能或任务是写代码/普通文案时，停止视觉流水线。
13. 均匀矢量点、LV 橱窗机器人、红发抱南瓜视为失败外观。
