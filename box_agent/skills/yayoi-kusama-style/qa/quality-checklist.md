# 质量检查清单

## 触发与模式

- [ ] 用户意图确实是草间向视觉 / 空间 / 致敬 / 诗性标题。
- [ ] 已选择 A/B/C/D，未把普通装饰波点强行称为本风格。
- [ ] 未误入写代码、纯公关讣闻、假授权。

## 红线

- [ ] 未声称原作、授权、可上拍。
- [ ] 未提供名作商业复刻施工。
- [ ] 未拿病痛猎奇。
- [ ] 未用「最贵女画家」腔带货。

## 风格落地

- [ ] 已锁年代/期；未指定时为黄/黑波点场吞噬，未自动加南瓜+LED 镜屋。
- [ ] 有一句非符号命题。
- [ ] 只有一套主母题（或主次写清）。
- [ ] 镜屋已写亚型，未把 1965 与 2010s 画成一间。
- [ ] 配色成对并跟年代走。
- [ ] 密度达到铺满或命题所需的过程态。
- [ ] 无默认红发表情包、无均匀矢量点当正确答案。
- [ ] 去掉艺术家姓名后，无限或消融仍成立。

## 结构

- [ ] 按模板交付；含一句「故意没做」。
- [ ] 产品模式含风险与对外文案约束。
- [ ] 空间模式能说出三幕身体感觉。
